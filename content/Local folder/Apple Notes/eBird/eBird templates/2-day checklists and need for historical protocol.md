You have indicated that this is a 2-day checklist. But, the protocol you have used is "Travelling" protocol. May I request you to please change it to the "Historical" protocol? This is because the "Travelling" protocol is typically when "... if reasonable estimates of start time, duration, and distance can be entered". For more details, see the section "Historical protocol" at this link: http://help.ebird.org/customer/portal/articles/974012-how-to-make-your-checklists-more-valuable
Ideally, the list needs to be split into 2 lists for each day and uploaded in the Historical protocol, but if the split-up list is not available day-wise, it is still fine I think. 

Please refer to your following checklist on eBird:
http://ebird.org/ebird/view/checklist/S16430657

You can easily edit the checklist above to alter the protocol. Please let me know if you edit the checklist, so that it does not remain as unconfirmed and hence hidden from eBird public output such as species maps.

Please do let us know if you have any questions about this. Thank you for your understanding and for any help that you can provide.
