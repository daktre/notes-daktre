Dear Prem Prakash Garg,

Thanks. Please note that it is totally your choice on whether to keep your record or not and eBird reviewers have no role in that matter. If the documentation is good enough for some species such as this, then the record will be “validated” on the back-end and the data of that particular observation will be made available for public display on maps and for researchers. If not, it will be marked invalid (on the back end). Note that invalid DOES NOT MEAN that the id skills were bad or that the observer did not id properly. It only means that (as in this case) there is insufficient documentation added to the observation to stand the test of time. 

So, please feel free to keep the observation if you were sure of the id. My role is only to flag situations wherever more documentation is needed. In some situations, if new information turns up (for example, you see the kite in the same location next season), let me know and I can always revisit this observation and validate it later! There is absolutely no time limit for this. Hope this clarifies.
